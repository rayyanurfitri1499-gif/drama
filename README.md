# Dramaku

Halaman nonton drama pendek dengan video 9:16, pilihan episode 1–3, tombol aplikasi dan saluran Telegram.

## File
- `index.html` — struktur halaman
- `style.css` — tampilan
- `script.js` — pengaturan link, episode, dan video

## Cara ubah
Buka `script.js`, ganti isi bagian `PENGATURAN` di paling atas (link, judul episode, video, poster).
